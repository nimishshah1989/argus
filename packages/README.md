# Packages

- `domain/` — ticket state machine, figures, severity, SLA maths, permissions; pure, 100% tested.
- `db/` — Drizzle schema, SQL migrations with RLS, seeds, imports, isolation test.
- `shared/` — Zod schemas, settings schema, i18n messages, constants.
- `engine/` — analytics port from M4; `python/` sidecar beside it.
