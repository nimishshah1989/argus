# Differences from Bhavin’s behaviour

Every deliberate departure from v3 or the analytics platform: old, new, why. Parity means matching intent, not defects.

| #   | Area                               | Old (v3 / platform)                                                                                                                                             | New (ours)                                                                                                                                                             | Why                                                                                                                 |
| --- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| D1  | Day report window                  | 24 hours from the day/shift start                                                                                                                               | The shift’s real start-to-end window (shift 2 crosses midnight); the production date is the date the shift started                                                     | The 24-hour window double-counts overlapping shifts; the plant thinks in shifts                                     |
| D2  | PDFs                               | Built in the browser with jsPDF; Gujarati becomes “[local-language text]”                                                                                       | Server-rendered with Playwright/Chromium and bundled Noto fonts; stored in S3 and linked to the ticket                                                                 | Correct Indic glyphs; shareable; auditable; no phone memory limit                                                   |
| D3  | Permissions                        | Client-side checks; the Worker contract does not prove server checks                                                                                            | Every command checks role/ownership on the server in `packages/domain`                                                                                                 | A browser is not a security boundary                                                                                |
| D4  | Names                              | Free-text `startedBy`, `crew[].name`, `by`; a shared phone can type any name                                                                                    | `person` rows; the acting person is chosen from the plant’s active people; free-text floor names become `pending` production persons for the admin to confirm or merge | Accountability; no invented people; the import can still resolve aliases                                            |
| D5  | Tenant identity                    | Company id and API base from the URL (`?c=`, `?api=`), saved on the phone                                                                                       | Tenant from the host name; no URL override                                                                                                                             | A crafted link could point a phone at a hostile server                                                              |
| D6  | Translation                        | Public Google Translate fallback sends problem text off-platform                                                                                                | Sarvam transcription + glossary; the person confirms; no public translation service                                                                                    | Data leaves the platform; privacy and accuracy                                                                      |
| D7  | Languages                          | English UI with Gujarati dictation                                                                                                                              | English + Gujarati in M1; Hindi at M5; transliterated Gujarati accepted everywhere                                                                                     | A real Hindi user/reviewer arrives with plant two; the floor needs Gujarati now                                     |
| D8  | Support → stopped                  | A stopped report on a machine with an open support ticket is blocked by the duplicate rule                                                                      | `upgradeKind` in place: the same ticket becomes `stopped`, and downtime starts at the upgrade                                                                          | Downtime would otherwise be lost or duplicated in a second ticket                                                   |
| D9  | Report “root cause”                | Displayed in the PDF payload but never written by the form                                                                                                      | A real `root_cause` field on `breakdown_report`                                                                                                                        | The form promised it; the data was lost                                                                             |
| D10 | PDF storage                        | Only the file name is sent; the PDF stays on the phone                                                                                                          | The PDF is stored in S3 and linked to the ticket                                                                                                                       | A report that only exists on one phone is not a record                                                              |
| D11 | Mine badge                         | Ignores crew membership while the Mine list includes it                                                                                                         | The badge counts crew too                                                                                                                                              | The badge and the list should agree                                                                                 |
| D12 | Utility machine hiding             | A hard-coded `LV_UTIL` regex when no groups are configured                                                                                                      | A `hidden` flag on the machine group                                                                                                                                   | No Cosmos regex in code; configuration decides                                                                      |
| D13 | Duplicate detection                | Only after the POST returns `{exists}`                                                                                                                          | Also checked live while typing (same rule: any open non-general ticket on the machine)                                                                                 | Fewer wasted submissions; the server remains the authority                                                          |
| D14 | `ref` numbering                    | Sequence implied, gaps unknown                                                                                                                                  | `ref_counter` row locked in the raise transaction; import sets it to the imported maximum + 1                                                                          | Gapless, traceable ticket numbers                                                                                   |
| D15 | Secrets and URLs                   | Keys/ids in URLs; client-side gating                                                                                                                            | No ids or keys in URLs; server permissions; Secrets Manager/SSM                                                                                                        | Security by default                                                                                                 |
| D16 | “Report only”                      | A PDF with no ticket; nothing enters the system                                                                                                                 | Creates a closed imported ticket with the form as overrides                                                                                                            | Nothing lives outside the record; the figures still reconcile                                                       |
| D17 | PWA install                        | Two pages with different manifests                                                                                                                              | Two installable faces (Report, Maintenance) and a kiosk board; one service worker                                                                                      | The floor and the desk are different jobs, not two copies of one page                                               |
| D18 | Live updates                       | 30-second polling only                                                                                                                                          | Polling in M1; web push for notifications; SSE later if a plant’s size demands it                                                                                      | Scope honesty: “pushed live data” was not specified or built                                                        |
| D19 | Team Focus and Action Center state | Acknowledge, owner, due, note, snooze and a Team Focus action's status were kept in one browser-side object, saved to the company settings blob; last save wins | One server-stored row per nudge and per Team Focus action (D31), changes by a signed-in person, names in notes erased with a leaver                                    | Two heads no longer overwrite each other; the state survives a new browser and is shared; erasure reaches the notes |
| D20 | Why-Why record                     | One record per breakdown, wiped when the breakdown is edited                                                                                                    | Each save is a history line on the closed ticket; the latest shows, earlier ones stay                                                                                  | Nothing is lost by an edit; the author and time come with the line                                                  |
| D21 | PDF import by QR                   | Scan a breakdown PDF to preview and apply it as a log entry                                                                                                     | Dropped. Tickets create the report; the 1,350 history rows load from the workbook; a late paper report goes through the past-breakdown path                            | Nothing left to import from; `breakdown_report.qr_payload` stays for printing (triage verdict `pdf-import`)         |
