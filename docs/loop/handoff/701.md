## PR body

## What changed and why

Hides Gujarati until Nimish switches it on (ADR 0036 R25, switch ADR 0038). With the `uptimo.gujarati` key off, every page shows English, the account sheet offers no language choice, and a `gu` company or a saved `gu` on the phone is ignored. The catalogues and `pickLanguage` stay, so turning it on later is a one-key change.

## How to try it

Open the app, go to the account sheet: no language choice is shown. In the browser console, run `localStorage.setItem('uptimo.gujarati', 'on')` and reload: the choice appears and Gujarati works again. To check the unit behaviour, run `pnpm exec vitest run apps/web/src/i18n`.
