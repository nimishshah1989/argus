# Handoff #594: TF-4 Team Focus "I'll take it" edge cases

## What changed

- `apps/web/src/screens/v2/team-focus/assign.ts`: `assignHandlers` built. Returns `{}` when `me` or `period` is null; otherwise `onAssign(id)` saves owner `me` and `onUnassign(id)` saves owner `''`.
- `apps/web/src/screens/v2/team-focus/TeamFocusLive.tsx`: uses `assignHandlers`. The save given to it catches its own failure and sets `assignFailed`, so the handlers never leave an unhandled promise. The old `quick` helper and the unconditional `onUnassign` are gone.
- `apps/web/src/screens/v2/team-focus/View.tsx`: `onAssign`/`onUnassign` have no `ignore` default, so `DecisionDetail` hides its button. New `assignFailed` prop renders the `v2tf.edit.failed` alert in the page body, directly above the decisions, via a small `AssignFailed` component (kept out of `Body` to stay under the 60-line lint cap).
- `apps/web/src/screens/v2/team-focus/local.tsx`: `Acts` makes `onAssign`/`onUnassign` optional. An `owner:<name>` drawer always returns an owner drawer, labelled from the ref id; it is never null.
- `changes/594-team-focus-assign-edges.md`: one changelog line.
