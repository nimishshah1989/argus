## Decisions to check

- Back link: the visible view test needs `href="/desk"` inside `TicketView`, so the "Open tickets" link is drawn by the View (first element, before the h1). `TicketPage` draws the TopBar back link only while loading or on error, so the page never has two "Open tickets" links. In the pane the TopBar is gone once loaded.
- "(running)" on Work time: the visible view test finds the first `dt` "Work time" (the fact) and expects `dd` = "47 min", so the fact value is the bare minutes and "(running)" is a `note` printed after the `dd`. Same words, outside the `dd`.
- v2 screens may not use Tailwind colour, size or weight classes (`ui:check`), so the facts, Minutes and cards use kit classes (`v2-facts`, `v2-fact-value`, `v2-yardstick`, `Panel`, `v2-title`). v1 look (tile grid, big minute numbers) is not reproduced pixel for pixel.
- Row marking for the `ticket.people` outlier (tag on the top worker's row) is not drawn: `PersonRows` has no slot for it. The takeaway line names them and carries `outlier` in the model.
- "Running work time" is v1's `figures.activeMin` as the server sends it; `now` is used for live downtime, per-person minutes without a cached figure and the since-reported yardstick (to `closedAt` once closed).
