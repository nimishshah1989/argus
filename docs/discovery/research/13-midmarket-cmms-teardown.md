# Research: mid-market and SMB CMMS capability teardown (28 Oct 2026)

The consolidated capability matrix (ours vs these vendors and the enterprise suites) is in the shared doc's "Capability matrix" tab. Key vendor facts:

- MaintainX: Autodesk agreed 28 May 2026 to acquire for ~$3.6B; >$135M ARR expected 2026. $0 / $20 / $65 per user/month, Enterprise custom; requesters free. Enterprise: Asset Health Insights, resource planning, escalations, custom permissions, IoT, SSO, multi-site, Global Parts/Procedures, Assist AI, Report Builder. AI: manual Q&A + procedure generation (Feb 2025), nameplate-to-asset, photo diagnosis, voice-note summaries (Jun 2025), AI procedure recommendations (May 2026), CoPilot Shared Assets across orgs (Jul 2026), Report Builder chat + AI Work Request by voice/chat/QR (Sep 2026). OT connectors: Ignition, Kepware, MQTT (Nov 2025). Sub-work orders, RCA (May 2026); Maintenance Plans, external IDs (Aug 2026). 29 languages incl. Hindi only. SOC 2, ISO 27001.
- UpKeep: $24 / $55, Professional/Enterprise quoted; Nova AI credits per tier; Nova chat, Pulse background analysis, Nova Apps (no-code), Voice Fill, Smart Checklist Builder, Photo-to-Part, summaries, AI import clean-up; Edge sensors (vibration, temperature, current, pressure, leaks); Studio apps; 26 languages, none Indian.
- Limble: Standard / Premium+ / Enterprise (calculator). Asset Snap, AI PM Builder, conditional procedures, automations, MCP connection, anomaly detection, BOMs, escalations, duplicate check, AI scheduling, 21 CFR, white-label; 27 languages, none Indian.
- Fiix: $0 / $45 / $75 / Enterprise. Foresight (Parts Forecaster, Asset Insights, Work Order Insights); Fiix MAX NL Q&A add-on; Augury Reliability Agent → Fiix MAX work orders (partnership Jul 2026); failure codes, custom workflows, e-signatures, audit trail on Enterprise.
- eMaint (Fluke): Professional (min 3 users) / Enterprise (min 5); calibration, condition triggers, e-signatures, sandbox, validation scripts add-on; AI suite beta (Mar 2026): data Q&A with voice, SOP Builder, multilingual manual Q&A, voice-to-WO.
- Fracttal: quote; PM by time/usage/events/meters; WhatsApp notifications on assignment (Fracttal HUB); IoT (Fracttal Sense, PLC, OPC, SCADA); AI triage drafting WO with history/parts/procedure, NL questions, agents, MCP, image-to-asset.
- Tractian: sensor-first (Smart Trac 75+ failure modes, Energy Trac, Omni Trac PLC/OPC UA/Modbus/S7/OEE); CMMS with sensor-triggered WOs; AI transcription, AI SOPs, checklists learned across customers.
- Eptura Asset: offline mobile, voice Technician Copilot, fleet telematics ML, BIM links; assistant inside Microsoft Copilot (preview).
- Brightly Asset Essentials (renamed Siemens Asset Management Software, Jul 2026): IoT-alert WOs, duplicate detection, Maintenance Copilot, parts recommendations.
- Coast: Free / $1.80 / $3.60 / Enterprise; chat per WO, LOTO templates, failed inspection → WO, Coast AI workflow builder, MCP, SOC 2.
- Maintenance Connection: Crue AI (Feb 2026), Esri GIS (Jun 2026), Analytics Central (Oct 2026).
- India: Keep Wisely ₹799/user/mo, WhatsApp requests, skill/shift auto-assignment, multi-level SLA escalation, AMC, OEE/Kaizen/5S, on-prem option; OxMaint $19/$49 (AI vision, AI shift logbook); Cryotos $29-69 (voice AI WOs, OEE, Permit to Work; WhatsApp/SMS Enterprise only); TeroTAM (Permit to Work, ISO 42001); InnoMaint (52-week PPM, FSSAI/HACCP).

## What leaders compete on in 2026
Agentic AI that acts; manuals → procedures (table stakes); voice as main capture; photo → record; MCP access for outside AI tools; OT connectivity (Ignition/Kepware/MQTT/OPC UA); bundled sensors; AI monetisation via tiers/credits/add-ons; cross-org shared knowledge (MaintainX Shared Assets); AI scheduling; conversational reporting; no-code builders; price compression at the bottom; Indian vendors win on WhatsApp, OEE/TPM, permits, on-prem — but only MaintainX names an Indian language (Hindi); consolidation (Autodesk-MaintainX, Siemens-Brightly, Rockwell-Augury).
