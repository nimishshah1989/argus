# Coverage: Data Checklist (v2, `screens/v2/data-checklist/`)

Built from `screens/analytics/DataChecklist.tsx` and `checklist-view.ts` (both deleted in the PR that made this screen
live), their unit tests (`checklist-view.test.ts`, the checklist half of `today-tabs.test.ts`), `e2e/analytics.spec.ts`
(the Today journey) and the engine figure `data-checklist` (`packages/domain/src/analytics/data-checklist.ts`, 16
groups). First listed in `scope/batch1.md` §3. The live adapter is DC-1 (#572, ADR 0017); going live is DC-2 (#578, ADR
0019).

**Live (DC-2).** The screen is at `/analytics/today/checklist` (v1's address, a tab of Today) on the engine's
`data-checklist` figure from `GET /analytics/figures`, the reply v1 read, through `ModelPage` and the seam: it refreshes
with the figures and keeps the page on screen while a refresh loads or fails. The gallery keeps the approved fixture
(`frozen`).
