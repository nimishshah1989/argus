# Coverage: OEM (`screens/v2/oem`)

**There is no OEM screen in v1 and the engine does not compute it.** `docs/plan/m4a-triage.md` marks OEM Analytics DEFERRED: the cause is a keyword guess with one
cause confirmed by a person, and the claim figure needs Bhavin's call first (N12). The registry leaves it out (`registry.ts`) and the Guide says "not in this build yet".
This screen is built from the platform's own OEM page (`fixtures/answer-key/oem-analytics.json`, the frozen 11 November output), so that the day the engine carries the
figure `oem-analytics` the screen shows it with no change. Until then the screen shows "Not computed yet".
