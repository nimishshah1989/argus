# Coverage: Machine page (`screens/v2/machine`)

**Live at `/analytics/machines/:id`** (the address v1 had; the id is the machine's id, and its code reaches the same page, as a drawer's "Open full page" link carries it), inside the v2 shell, for the roles v1 allowed; v1's page is deleted.
The e2e `apps/web/e2e/analytics-machine-reliability.spec.ts`, `analytics-machines.spec.ts` (the machine-page part), `pm-calendar.spec.ts` (the Tasks block) — all v1's, ported — and `v2-machine-live.spec.ts` (real server) run it.

Rebuilt 20-Nov-2026 from the engine's `machine-page` figure (`machine-record.ts` reads it) and `reliability` figure (`reliability-values.ts`), the machine's open tickets (`GET /tickets?machineId=`, as v1's Tasks block read them) and the plant's list.
The adapter is `screens/v2/machine/adapter.ts`; its tests run the real engine over the frozen 11 November answer key (HMC-2: 43 failures, a fitted Weibull, four spares) with v1's edge cases ported.
