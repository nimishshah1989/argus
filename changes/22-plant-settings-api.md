- The maintenance head or the admin can now list, add and edit machines, segments, machine groups and shifts through the server (the settings screens will call these). Nobody else can: operators, technicians, supervisors, plant heads and board logins are refused, and one plant can never see or change another's.
- Moving a machine to another cell now writes one dated record (from, to, effective date) that can be read back for the machine page; an edit that leaves the cell alone writes none. Hiding a group, hiding a segment from the board, changing a machine's importance and switching a machine off are each recorded with who did it and the value before and after.
- A machine is never deleted: "switch off" keeps it and all its tickets, and it can be switched on again. A switched-off machine no longer appears in the machine picker.
