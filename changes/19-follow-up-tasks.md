- A job left unfinished at close can now become a follow-up task: the close takes the task's words, reason and expected date and raises a linked work request. The ticket's detail lists its tasks (pending, in progress, overdue, done) with a headline for the parent. A task can be finished in one step, with the minutes the machine stood still (0 to 1440), kept apart from the breakdown's downtime. A task runs no SLA clock, and a task line on a breakdown no longer holds back its back-dated times. The open tickets already name a task's machine, so the phone can warn before a report is raised on it. The screens that use this come next.
