- A queued command the server refuses for good (on the floor phone too) ("this was queued for someone else") no longer blocks everything behind it: it moves to "Needs attention" with "Could not send: this was queued for someone else" and the rest of the queue goes on. Commands now act as the person the phone last learned from the server, so switching who is using a shared phone cannot send the old person's name.
- "Who is using this phone?" now lists only the people the server allows this shared phone to choose, and the server picks the acting person from the session rather than from the app. Only maintenance can start work while raising a complaint.
- Signing out (or changing your password) no longer leaves a phone silently without alerts: the next time the same person signs in, the phone registers for notifications again.
