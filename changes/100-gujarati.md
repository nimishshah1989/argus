- A plant set to Gujarati now sees the whole app in Gujarati: the floor's report flow, My complaints, the desk lists, the ticket screen, the close and report forms, sign-in, settings, the live board and every status chip. The wording is short, plain factory Gujarati. It keeps the plant's own English loanwords in Gujarati script (મશીન, બ્રેકડાઉન, રિપોર્ટ), so a closed ticket (ક્લોઝ) never reads like a stopped machine (બંધ). The term list is `docs/design/gujarati-glossary.md`. The strings a native speaker should check first are in `docs/design/gujarati-review.csv`. The page also tells the phone it is in Gujarati, so screen readers and text shaping use Gujarati.
