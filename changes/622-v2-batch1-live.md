The Machine page has the new look at its old address and now shows the plant's own figures: age, size and load, breakdown figures, reliability fit, critical spares, open tasks, cell moves, nameplate, PM and record completeness, each block opening the rows behind it. A machine can be opened by its code as well as its id. The old page is gone. Invented sections the plant has no data for (a 12-week trend, spare stock) are not shown.
