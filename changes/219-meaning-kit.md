- The design kit now has one map for icons and colour: each machine segment has its own icon shape (CNC a cog, Utility a lightning bolt, and so on), and a machine's colour only ever comes from its live status. New filter chips show an icon, a word and a count; a selected chip gets a tint, a ring and a tick, so it reads without colour. Task statuses (Pending, Overdue, In progress, Done) join the status chips. Nothing on today's screens changes yet; the settings, people, audit and task screens use these pieces next.
